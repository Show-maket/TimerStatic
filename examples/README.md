# Примеры использования библиотеки TimerStatic

Эта папка содержит примеры использования библиотеки TimerStatic для Arduino.

## Список примеров

### 1. BasicBlink
**Файл:** `BasicBlink/BasicBlink.ino`
**Описание:** Базовый пример мигания светодиодом с помощью таймера.
**Особенности:** Демонстрирует простейшее использование таймера для периодических задач.

### 2. DelayReplacement
**Файл:** `DelayReplacement/DelayReplacement.ino`
**Описание:** Демонстрирует замену блокирующей функции `delay()` на неблокирующий таймер.
**Особенности:** 
- Показывает, как заменить `delay(2000)` на таймер
- Во время ожидания светодиод продолжает мигать
- Демонстрирует неблокирующее поведение

### 3. ForLoopReplacement
**Файл:** `ForLoopReplacement/ForLoopReplacement.ino`
**Описание:** Демонстрирует замену блокирующих циклов `for` на неблокирующие таймеры.
**Особенности:**
- Заменяет `for(int i=0; i<5; i++)` на таймер
- Выполняет 5 итераций с интервалом 1 секунда
- Во время выполнения цикла светодиод продолжает мигать

### 4. AdvancedForReplacement
**Файл:** `AdvancedForReplacement/AdvancedForReplacement.ino`
**Описание:** Продвинутый пример замены вложенных циклов `for` с помощью множественных таймеров.
**Особенности:**
- Демонстрирует замену вложенных циклов
- Внешний цикл: 3 итерации с интервалом 2 секунды
- Внутренний цикл: 4 итерации с интервалом 500мс
- Показывает координацию нескольких таймеров

### 5. ButtonDebounce
**Файл:** `ButtonDebounce/ButtonDebounce.ino`
**Описание:** Демонстрирует реализацию антидребезга кнопок с помощью таймеров.
**Особенности:**
- Заменяет блокирующие delay() для антидребезга
- Показывает два способа реализации
- Демонстрирует счетчик нажатий
- Во время антидребезга светодиод продолжает мигать

### 6. MultipleTimers

**Описание:** Демонстрирует работу с несколькими таймерами одновременно.
**Особенности:** Показывает, как управлять множественными таймерами в одном проекте.

## Схема подключения

Для большинства примеров требуется:
- Arduino плата
- Светодиод (подключен к пину 13 или LED_BUILTIN)
- Кнопка (подключена к пину 2 с подтягивающим резистором)

## Основные принципы

### ⚠️ Важно: Правильная реализация антидребезга

При реализации антидребезга кнопок **НЕ используйте** блокирующие конструкции:

```cpp
// ❌ НЕПРАВИЛЬНО - блокирует основной цикл
while (digitalRead(BUTTON_PIN) == LOW) {
  Timer::tick(); // Это все еще блокирующий код!
}

// ✅ ПРАВИЛЬНО - неблокирующий код
if (buttonPressed && !isButtonProcessed) {
  debounceTimer.delay(50, millis, []() {
    if (digitalRead(BUTTON_PIN) == LOW) {
      isButtonProcessed = true;
      // обработка нажатия
    }
  });
}
```

### Замена delay()
```cpp
// Вместо этого (блокирующий код):
delay(2000);
Serial.println("2 секунды прошли");

// Используйте это (неблокирующий код):
delayTimer.delay(2000, millis, []() {
  Serial.println("2 секунды прошли");
});
```

### Замена циклов for
```cpp
// Вместо этого (блокирующий код):
for(int i=0; i<5; i++) {
  Serial.println("Итерация " + String(i));
  delay(1000);
}

// Используйте это (неблокирующий код):
forTimer.forCount(1000, millis, []() {
  Serial.println("Итерация " + String(counter++));
}, 5);
```

### Замена delay() для антидребезга
```cpp
// Вместо этого (блокирующий код):
if (buttonPressed) {
  delay(50); // Антидребезг
  // обработка нажатия
}

// Используйте это (неблокирующий код):
if (buttonPressed && !isButtonProcessed) {
  debounceTimer.delay(50, millis, []() {
    // обработка нажатия после антидребезга
    if (digitalRead(BUTTON_PIN) == LOW) {
      // Кнопка действительно нажата
      isButtonProcessed = true;
      // обработка нажатия
    }
  });
}
```

## Преимущества использования таймеров

1. **Неблокирующее выполнение** - основной цикл не останавливается
2. **Многозадачность** - можно выполнять несколько задач одновременно
3. **Точное время** - таймеры работают независимо от других операций
4. **Гибкость** - легко изменять интервалы и количество повторений
5. **Читаемость кода** - логика таймеров отделена от основного цикла
