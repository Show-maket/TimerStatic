# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.2.0] - 2025-08-22

### Added
- Enhanced timer lifecycle management
- Support for count-based and time-based timer lifecycles
- Improved memory management with move semantics
- Better error handling and validation
- Comprehensive test suite
- PlatformIO support
- Arduino Library Manager compatibility

### Changed
- Restructured library to follow Arduino library standards
- Improved documentation and examples
- Enhanced AVR compatibility
- Better cross-platform support

### Fixed
- Memory leaks in timer management
- Issues with timer linking/unlinking
- Callback parameter handling

## [2.1.0] - 2024-12-01

### Added
- Lifecycle management features
- Count-based timer limits
- Time-based timer limits

### Changed
- Improved timer performance
- Better memory efficiency

## [2.0.0] - 2024-06-15

### Added
- Complete rewrite with improved architecture
- Support for std::function and lambda expressions
- Enhanced callback system
- Better timer management

### Changed
- Major API changes for better usability
- Improved performance and memory usage

## [1.0.0] - 2024-01-01

### Added
- Initial release
- Basic timer functionality
- AVR compatibility
- Simple callback system
